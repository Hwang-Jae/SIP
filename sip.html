📊 프로젝트 개요 및 기대 효과

스마트 팩토리 내 폭증하는 비정형 미디어 데이터를 효율적으로 관리하고 지능적으로 탐색하기 위한 차세대 하이브리드 포털 구축안입니다.

💡 추진 배경 및 목표

  • ⚠️ 데이터 급증: 도면, 공장 전경, Vision 센서 등 비정형 데이터 폭증.
  • 🐢 성능 한계: 기존 RDBMS 직접 저장 시 I/O 병목 및 쿼리 저하 발생.
  • 🔍 검색 한계: 단순 텍스트 일치 기반으로 자연어 시맨틱 탐색 불가.
  • 🚀 해결책 1: 하이브리드 구조: 파일은 로컬/S3, 메타데이터는 ClickHouse 분리.
  • 🤖 해결책 2: 로컬 AI RAG: Ollama를 활용한 오프라인 지능형 검색 챗봇 연동.

📈 성능 개선 기대치 (예측)

대용량 이미지 쿼리 응답 속도 비교 (Blob vs Hybrid)

📁 관리 대상 데이터 분포

시스템에 적재될 주요 데이터의 특성 및 비중입니다.

  • 📐 도면 (Blueprint) 설비/배관 CAD 등
  • 🏭 공장 전경 (Factory) CCTV, 레이아웃 등
  • 👁️ Vision 데이터 양불 판정 센서 (OK/NG)

✨ 주요 기능 명세

사용자 편의성과 관리 효율성을 극대화하기 위한 4대 핵심 기능을 제공합니다.

🗂️

분류별 데이터 브라우징

직관적인 탭 UI를 통해 3대 핵심 미디어를 빠르게 탐색합니다.

  • 📐 도면: 캐드 도면, 설비 배치도, 소방 배관도 등
  • 🏭 전경: 실시간 CCTV 캡처, 가동 장비 외경 등
  • 👁️ Vision: 판정용 센서 미디어 (OK/NG 데이터)
🔢

스마트 채번 자동화

규격화된 코드를 자동 생성하여 데이터 추적성을 확보합니다.

  • 일괄 업로드: 여러 이미지를 동시 적재 지원
  • 동적 폼: 각 장별 상세 메모 및 제목 개별 기입
  • 자동 채번: FAC-YYYYMMDD-XXXX 규칙 적용 동기화
🗑️

대량 일괄 관리 (Bulk Admin)

오탐지 파일이나 폐기된 도면을 안전하고 빠르게 일괄 정리합니다.

  • 다중 선택: 체크박스를 통한 대량 목록 선택
  • 하이브리드 파기: DB 인덱스와 로컬 파일을 동시 영구 삭제
  • 고속 처리: ClickHouse ALTER TABLE ... DELETE 기반
🤖

Ollama RAG 증강 검색

자연어 질의를 이해하고 결과를 브리핑하는 지능형 챗봇입니다.

  • 인텐트 파싱: "NG 비전 데이터만 보여줘" 구어체 인식
  • JSON 추출: 로컬 LLM이 검색 조건 및 키워드 완벽 파싱
  • RAG 임베딩: 검색 결과를 바탕으로 한국어 요약 브리핑 생성

🗄️ 데이터베이스 설계 (ClickHouse)

초고속 집계와 검색 최적화를 위한 image_data MergeTree 스키마 정의입니다.

테이블 명세

컬럼명 데이터 타입 설명 인덱스 / 비고
💡 정렬 키: 업로드 날짜 기준 고속 정렬 및 기간 탐색 효율 극대화를 위해 ORDER BY uploaded_at이 적용되어 있습니다.
